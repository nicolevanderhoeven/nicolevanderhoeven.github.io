obsidian-okrs

Templates I use to set and review OKRs and goals in Obsidian, from core principles down to the daily note.

  • Source code

obsidian-okrs is the set of templates I use to set up OKRs (Objectives and Key Results) and goals in Obsidian, as described in the video I made about them (and its blog post).

New Year’s resolutions are infamously left undone. Setting OKRs instead, and reviewing them as you go, gives you a better chance of following through, and keeping them in Markdown notes means the goals live right next to the work they describe.

The templates

The templates are organized into five levels, each one feeding the next:

  1. Core Principles: the values everything else hangs off.
  2. Yearly: a Yearly OKRs note, a template for each individual objective, and a Yearly Review.
  3. Monthly: initiatives, in the form of a monthly review.
  4. Weekly: weekly goals and a weekly review.
  5. Daily: a daily note template.

What you need

The templates use Obsidian’s core Templates plugin plus the community plugins Admonition and Templater. QuickAdd, Periodic Notes, Calendar, and the core Daily Notes plugin are optional extras that make creating the periodic notes smoother.
